Web Technologies

HTML

HTML (HyperText Mark up Language) is the standard mark up language for web browsers. It helps with things such as CSS (cascading Style Sheets) or coding languages such as Java Script. Its the thing that defines the structure of most web content you will see.

CSS

CSS (Cascading Styling Sheets) is exactly as its name might suggest. It is a style language sheet used for presentation written documents, it can be used for things such as coloring your text or fonts.

Java Script

Javascript is a core coding language, its code having build the World Wide Web, and even HTML and CSS. It is most widely used on github.

Python

Python is a highly general use programming language that is easy to use being known for its simplicity. It is widely taught in schools since it is very beginner friendly.
